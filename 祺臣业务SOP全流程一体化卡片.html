12 阶段 SOP 卡片（可搜索）

S1 · 询盘接收与分级售前主责：业务员 + A1 诊断官
目标每条询盘在录入 CRM 的同时完成 A/B/C 分级，资源向 A 级倾斜。
关键动作
  1. 登记询盘来源/时间/客户信息（编号 QC-YYYYMMDD-___）；
  2. 勾选信号：参数充分度（杯型/产量/淋膜/技术问句/公司信息）；
  3. 定级：信息≥4项=A；2–3项或有画像信号=B；其余=C；
  4. 同步扫风险清单：只要最低价/回避公司信息/先发货后付款/异常账期。
输出物 & 时限询盘登记记录 + 分级标签；分级在收到后 2h 内完成。
红线命中「先发货后付款」=高危，付款必须走 Trade Assurance 或 30/70；未分级不许报价。
关联画像指南·询盘快速分级工具；AGENTS A1；MEMORY §1（响应≤6h 为店铺承诺，A 级首复对齐此时限）。
S2 · 客户画像诊断卡售前主责：业务员 + A1 诊断官
目标为每条 A/B 级询盘建画像卡，确定话术与机型方向。
关键动作
  1. 按标准模板填画像卡（基本信息→画像判定→需求→缺口→风险→跟进）；
  2. 判定主画像：P1 初创 / P2 工厂扩产 / P3 贸易商 / P4 连锁自用（混合画像以决策关注点为准）；
  3. 初判推荐机型方向（出处 MEMORY §2）；
  4. 列出「需求四问」缺口：日产量/杯型/热饮冷饮/当地电压。
输出物 & 时限完整画像卡一张；A 级 4h 内、B 级 24h 内建档。
红线画像不许编造——判断不了就标「待确认」，用首复反问收集信息。
关联画像指南·标准画像模板；MEMORY §4.1 四类画像；MEMORY §2 机型档案。
S3 · 首次响应（六段式英文回复）售前主责：A2 回复工程师
目标首复建立专业第一印象，并拿到关键缺口信息。
关键动作按 A2 六段结构起草：
  1. 称呼+感谢+需求共鸣；
  2. 推荐机型+2–3 关键参数（出处 MEMORY §2）+一句原理说明；
  3. 参数翻译成生意价值（净产出按额定×70–80% 算）；
  4. 反问 2–3 个缺口（需求四问）；
  5. 信任背书：16 年金品+SGS+Trade Assurance+视频验厂邀请；
  6. 明确下一步行动（视频通话/目录/样品杯）。
输出物 & 时限A 级 6h / B 级 24h / C 级 48h 内发出（对齐店铺 ≤6h 响应承诺，A 级优先）。
红线首复不报死价（区间价+配置说明，折扣老板拍板）；不夸大产能；不用 best/top quality 空洞词。
关联AGENTS A2；100问 Q81–Q92 买家FAQ口径；案例 C1（信任三连）/C9（多问题逐条答）。
S4 · 培育跟进节奏售前主责：业务员（A3 陪练可模拟）
目标B 级养成 A 级；C 级轻触达不耗资源；沉默客户按预案激活。
关键动作
  1. 按画像定频率：P2 工厂扩产 3–5 天、P1 初创 5–7 天、P3 贸易商报价后 3 天内回访、P4 方案书节奏；
  2. 每次跟进必带新价值：数据/视频/案例/算账，禁止空手催单；
  3. 14 天无回应→激活预案：换触点（邮件→WhatsApp）→换新价值（新机型/PLA 趋势/验厂邀请）→三次无回应降培育池月度轻触达；
  4. 跟进记录回写画像卡，标记沉默原因供 A6 复盘。
输出物跟进记录（日期/内容/客户反应/下一步）；每周随 A6 简报汇总。
红线禁止连续追问「did you receive my email」；禁止信任未建立前逼单（SOUL 铁律 4）。
关联画像指南·跟进指南阶段 0–4；案例 C10/C12 应对弹药。
S5 · 需求确认与选型算账售中主责：业务员 + A4 报价参谋
目标把模糊需求变成明确选型：机型、数量、配套、产能匹配全部敲定。
关键动作
  1. 补齐需求四问（日产量/杯型/热饮冷饮/电压），确认淋膜要求（单PE/双PE/PLA）；
  2. 按选型公式算机台数：峰值日产量×1.2 ÷ (净速度×运行小时)；
  3. 净产出按额定×70–80% 计算并展示给客户（主动讲，不等客户问）；
  4. 确定配套：空压机（必配）+包装机+杯盖机（双层线）+易损件包；
  5. 多杯型客户必讲换模时间（我方实测值待补 Q73，先给流程承诺）。
输出物选型算账表（机型×数量×产能匹配×配套清单）。
红线净产出系数不许省略（铁律 2）；PLA 兼容性未确认的机型不承诺能跑（Q78 待补→升级工厂工程师）。
关联100问 Q65–Q72 产能模块；案例 C5（5万只选型）/C6（单双PE纠偏）/C3（咖啡店整线）。
S6 · 报价方案（A4 参谋）售中主责：A4 报价参谋 → 老板审批
目标输出结构化报价单，凸显整线价值与信任保障。
关键动作
  1. 整线结构报价：主机+辅机（空压机/包装机/模具/易损件包）分项；
  2. 贸易条款：EXW / FOB Ningbo / CIF 分项呈现，凸显 Trade Assurance；
  3. 附加值包装：安装调试视频指导、操作培训、易损件包、一年质保（行业惯例 1–2 年）；
  4. 付款方式口径：30% 定金+70% 发货前，或信保在线支付；
  5. 价格区间参考 MEMORY §2 挂牌价，成交价由老板定。
输出物 & 时限正式报价单（PDF）；A 级客户 6h 内出，B 级信息补齐后 24h 内出。
红线A4 只建议不拍板；折扣幅度、账期、独家代理一律标注「需老板确认」；成本价与利润结构保密（SOUL 保密红线）。
关联AGENTS A4；MEMORY §2 机型价格带；100问 Q43/Q89/Q99。
S7 · 谈判让步与成交售中主责：业务员（让步走老板审批）
目标消除最后顾虑促成签约，同时守住价格与条款底线。
关键动作
  1. 按犹豫原因对症：怕机器不行→视频试机/FAT；怕工厂不实→视频验厂+SGS 报告；嫌贵→总拥有成本四件套；
  2. 比价应对（印度供应商等）：净产出率/纸耗 3–5% vs 8–10%/备件服务/认证背书，不贬低同行；
  3. 客户施压折扣/账期：审批流程做挡箭牌，把话题拉回价值（案例 C11 四步拆解）；
  4. 成交信号出现（问付款/安装/合同条款）→立即推进合同流程；
  5. 所有让步逐条记录并报老板审批，批准后方可书面确认。
输出物谈判记录（客户诉求/我方回应/让步申请/老板批复）。
红线四类让步（折扣/交期/账期/独家）未经老板书面批准不得写入任何文件；不编造实测数据换成交。
关联案例 C10/C11/C12；100问 Q93–Q99 异议应对；SOUL 行为边界。
S8 · 合同与付款售中主责：业务员 + 老板
目标合同条款与付款落地，锁定订单进入生产。
关键动作
  1. 合同要素核对：机型/数量/配置/杯型模具/电压（客户当地标准，印度 415V 等需注明）/交期/付款方式/质保条款；
  2. 付款走 Trade Assurance 或 30% 定金到账；
  3. 交期承诺以老板/生产部确认的口径为准（常规交期待补 Q88，确认前不写入合同）；
  4. 收到定金后 24h 内发确认函+生产排期；
  5. 同步建「交付跟踪单」：订单号/机型/交期/客户联系人/电压特殊要求。
输出物签署合同 + 定金/信保支付凭证 + 订单确认函。
红线交期未获生产部确认不得写入合同；电压/定制需求必须白纸黑字进合同，防止交付纠纷。
关联MEMORY §5 FAQ#11/#12；100问 Q25（电压）/Q88/Q89。
S9 · 生产 QC 与出厂验收交付主责：工厂生产/QC + 业务员跟踪
目标机器按合同配置生产并通过出厂测试，客户远程可见。
关键动作
  1. 按合同配置单投产（机型/电压/模具/语言界面）；
  2. 出厂测试：空载运行+带纸试机，记录运行状态；
  3. 试机视频与照片发客户确认（补 Q92 素材缺口的最佳时机——每单积累素材库）；
  4. 易损件包按清单随货装箱（切刀/加热元件/滚花轮/超声波焊头，Q23）；
  5. 客户远程验收确认（视频连线看试机）后安排发货。
输出物出厂测试记录 + 试机视频 + 装箱清单。
红线试机视频不许用其他机型素材顶替（真实是信任底线）；易损件包漏装=售后隐患。
关联MEMORY §1 成品检验/QC 服务能力；100问 Q23/Q92。
S10 · 物流发货与单证交付主责：物流/单证 + 业务员通报
目标机器安全到港，单证齐全，客户全程知情。
关键动作
  1. 运输规划：整机约 2.5 吨/约 2700×1400×1900mm，按 20GP 集装箱装载（Q24）；
  2. 出口单证：发票/装箱单/提单/原产地证（按客户要求）；
  3. 发货后 24h 内通报客户：提单号/船期/预计到港；
  4. 到港前 7 天提醒客户准备清关与厂房条件（380V 电力+空压机气源，Q25/Q26）；
  5. 尾款按合同节点收取（发货前或见提单副本，以合同为准）。
输出物提单 + 全套单证 + 物流节点通报记录。
红线店铺承诺 100% 准时发货率（MEMORY §1）——排期异常必须提前预警客户，不许瞒报。
关联100问 Q24/Q25/Q26；MEMORY §1 履约数据。
S11 · 安装调试与培训售后主责：工厂工程师 + 业务员
目标机器在客户现场跑起来、工人会操作——这是复购与转介绍的地基。
关键动作
  1. 安装方式确认：视频指导（默认）或工程师海外安装（客户承担差旅，Q85）；
  2. 现场条件核查：380V/三相电力、空压机气源、地面水平（Q25/Q26）；
  3. 调试要点传达：热风温度/超声波压力不可过高、滚花轮压力不可随意加大（Q19/Q20/Q21）；
  4. 操作培训：免费培训，教八工位流程与日常维护检查项（加热器/滚花轮/焊头/转盘同步，Q22）；
  5. 试产验收：客户用自购纸试产，确认杯型质量后签验收单。
输出物安装验收单 + 培训记录 + 客户现场试产视频（入素材库）。
红线客户纸张与机器不兼容时如实说明并协助调纸，不许硬推机器问题（维护口碑）。
关联100问 Q19–Q22/Q85；案例 C2（操作焦虑化解）。
S12 · 质保维护跟踪与复盘售后主责：业务员 + A6 复盘官
目标质保期内响应快、质保期外不断线；把每台机器变成长期客户与案例源。
关键动作
  1. 维护跟踪表：每客户一档——机型/出厂日/质保到期日/易损件更换记录/故障记录；
  2. 30 天回访：运行情况+易损件提醒（备件包复购机会，Q23）；
  3. 90 天回访：产能达成情况+扩产需求探测（P4 加机/P2 加线）；
  4. 质保响应口径：一年质保+易损件包+国际服务中心（Q86）；远程诊断与备件时效细则待补 Q80，到位前给「工程师 X 小时内响应」的个案承诺；
  5. 案例授权：稳定运行 6 个月后邀请客户授权案例/视频——新客户最高信任弹药；
  6. A6 周复盘：丢单原因/新问题沉淀进 MEMORY（§5 扩展 FAQ 与 §4 买家画像）。
输出物维护跟踪表 + 回访记录 + 案例授权书 + 周复盘简报。
红线收款后失联=最大禁忌——机械客户终身价值在备件+加机+转介绍；质保外故障也须响应（报价维修）。
关联画像指南·阶段5 客户成功；AGENTS A6；MEMORY §5 FAQ#8；100问 Q23/Q80/Q86。

试产杯型质量不佳S11先排查纸张（GSM/淋膜是否达标 Q55–57）再排查机器参数（温度/压力 Q19–Q21）不硬推机器问题，协助客户调纸

客户投诉/差评威胁S1224h 内响应致歉+方案；升级老板介入重大投诉不与顾客争执对错，先解决再复盘
